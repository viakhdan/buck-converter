# buck-converter
Designing and implementing a Buck Converter in MATLAB Simulink.

The goal here is for me to learn more about PMICs by designing and implementing a Buck Converter from scratch. 
Design goal is to step-down 12V to 5V, a typical application (car USB chargers, powering microcontrollers).

Full specifications and report on the done work are available in the Report.pdf file.

MATLAB version 2024b.
Required dependencies: Simulink, Simscape, Simscape Electrical.
